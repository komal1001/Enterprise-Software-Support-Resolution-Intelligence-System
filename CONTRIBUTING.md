# Contributing

Thanks for your interest in contributing to this project.

## How to contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes with clear, focused commits.
4. Run the relevant tests before opening a pull request.
5. Submit a pull request with a clear description of the change.

## Code standards

- Follow the existing project structure and naming style.
- Keep changes focused and easy to review.
- Add or update tests for behavioral changes.
- Avoid committing secrets or credentials.

## Reporting issues

- For bugs or feature requests, open a GitHub issue.
- For security issues, follow the private reporting process in [SECURITY.md](SECURITY.md).

## Pull request checklist

- The change is relevant to the project.
- The code is tested where practical.
- Documentation is updated if needed.
- No secrets or sensitive environment values are included.

Thank you for helping improve the project.
